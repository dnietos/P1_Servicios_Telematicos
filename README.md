# Smart Room

Práctica 1 de la asignatura Servicios Telemáticos.

## Descripción

Aplicación web para la gestión de una Smart Room. Permite consultar la información de la habitación, visualizar los sensores, configurar sus datos y guardar el nombre del usuario.

## Páginas

- `index.html`: página principal de Smart Room.
- `config.html`: formulario de configuración de la habitación y los sensores.
- `minombre.html`: permite guardar el nombre del usuario.
